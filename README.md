# Controle de Gastos — Python + MySQL (4º bimestre, Aula 1)

Ordem pra deixar tudo pronto:

1. No MySQL Workbench, abrir e executar `setup.sql` (cria o banco, as tabelas e dados de exemplo; pode rodar de novo sem duplicar nada).
2. `pip install -r requirements.txt`
3. Trocar `"sua_senha"` pela senha do MySQL em `verificar.py`, `listar.py` e `listar_desafio.py`.
4. `python verificar.py` — confirma conexão e quantidade de linhas por tabela.
5. `python listar.py` — o código da aula.
6. `python listar_desafio.py` — gabarito do desafio (valor maior que 50).
